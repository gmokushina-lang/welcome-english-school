# Welcome — языковая школа

Текущий дизайн сайта: dist/v2. GitHub Pages публикует эту папку автоматически при обновлении main.

Есть RU/EN, отзывы-карусель и демонстрационная форма записи. Форма пока не отправляет заявки. Панель /admin/ работает как локальная демонстрация; облачная авторизация и публикация ещё не подключены. Фотографии в макете иллюстративные.

Firebase отложен до согласования дизайна. Инструкция: FIREBASE-SETUP.md.
