# Подключение Welcome к бесплатному Firebase Spark

Панель: /admin/. Без Firebase работает явно обозначенная локальная демонстрация. Локальный черновик не меняет сайт других посетителей.

1. Откройте https://console.firebase.google.com/ и создайте отдельный проект Welcome. Оставьте тариф Spark. Analytics для этой задачи не нужен. Платёжный аккаунт, Storage и Functions не подключайте.
2. Добавьте веб-приложение (значок </>). Скопируйте объект firebaseConfig и замените null в dist/v2/firebase-config.js этим объектом. Не используйте ключ сервисного аккаунта.
3. Authentication → Sign-in method → Email/Password: включите вход. Users → Add user: создайте учётную запись владелицы. Пароль вводите самостоятельно, не передавайте в чат. Скопируйте UID пользователя.
4. Firestore Database: создайте базу в production mode. В Rules опубликуйте содержимое firestore.rules. Не включайте test mode.
5. Через консоль Firestore создайте коллекцию siteAdmins, документ с ID, равным UID владелицы. Добавьте поле enabled: true. Этот документ создаётся вручную через консоль; сайт не может назначать администраторов.
6. В Firebase Authentication → Settings → Authorized domains добавьте домен сайта. Для локальной проверки добавьте localhost и используйте http://localhost:4174/v2/.
7. Перед публичным запуском проверить на настоящем проекте: неавторизованный пользователь не читает draft и не пишет published; владелица сохраняет draft; предпросмотр показывает изменения; публикация меняет сайт при обновлении; RU/EN работают.
8. Firebase CLI: firebase login, затем firebase deploy --project ВАШ_PROJECT_ID --only hosting,firestore:rules из этой папки. Используется firebase.json. Он размещает именно текущий вариант dist/v2 в корне сайта, панель будет /admin/.

## Что уже реализовано
- Редактор существующих текстов, программ, цен и отзывов на русском и английском.
- Поиск и фильтр по разделам.
- Черновик, предпросмотр, выгрузка резервной копии текстов.
- Подключение Firebase Auth и Firestore, публикация отдельно от черновика.
- Закрытые правила записи и чтения черновиков. Публично доступен только published.

## Ограничения первой версии
- Новые карточки и разделы пока не добавляются: редактируются существующие.
- Фотографии находятся в файлах сайта и меняются отдельно.
- Форма заявки пока демонстрационная, не собирает и не сохраняет обращения.
- Опубликованные изменения видны после обновления страницы.
- Правила проверены в проекте welcome-language-school: публичное чтение published разрешено; чтение draft и запись без входа запрещены. Первый вход владелицы, сохранение и публикацию нужно проверить после установки пароля.
- После изменения структуры HTML проверьте поля редактора: ID текстов вычисляются из исходного текста, а не из его положения.
- Бесплатные лимиты Spark ограничены; следите за использованием в консоли.

## Подключённый проект
- Project ID: welcome-language-school, тариф Spark без платёжного аккаунта.
- Сайт: https://welcome-language-school.web.app/
- Редактор: https://welcome-language-school.web.app/admin/
- Первый вход: введите свою почту, нажмите «Получить / восстановить пароль», задайте пароль по ссылке из письма и войдите. Пароль не передавайте разработчику.
- Доступ редактора выдаётся отдельно документом siteAdmins/<UID> с enabled: true. Регистрация сама по себе не даёт права редактировать сайт.
- Первым администратором настроен аккаунт разработчицы. Для передачи клиентке создайте её отдельную учётную запись и выдайте доступ её UID.
